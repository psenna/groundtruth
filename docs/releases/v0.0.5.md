# groundtruth v0.0.5

Per-role control of a model's reasoning/thinking effort, plus a startup-crash fix.

## `reasoning_effort` on a model config

Reasoning models (Qwen3, OpenAI o-series, gpt-oss, …) emit a chain of thought
before their answer. For groundtruth's agent loops that thought is pure overhead —
a single organize call against a local Qwen3 MoE spent ~1000 reasoning tokens per
turn and pushed a 3-minute job past 15 minutes.

`models.<role>.reasoning_effort` is now sent verbatim as `reasoning_effort` on
every chat-completions request for that role:

```yaml
config:
  defaults:
    models:
      default:
        base_url: http://ollama:11434/v1
        model: qwen3:30b-a3b
        api_key_env: GT_API_KEY
        reasoning_effort: none   # inherited by tag / reduce / answer
```

- **Ollama** maps `none` to "thinking off" for Qwen3-class models.
- **OpenAI** accepts `minimal` / `low` / `medium` / `high`.
- Leave it unset (the default) to send nothing and get the backend's own default.

Like `base_url` and `api_key_env`, a value on `models.default` is inherited by the
`tag` / `reduce` / `answer` roles unless they set their own.

## Startup no longer crashes on a job whose vault was removed

If a vault was deregistered while one of its jobs was still queued or running,
the next restart crashed in a loop: restart recovery (§4.4) tried to `git status`
the vanished repo, `subprocess` couldn't `chdir` into the missing directory, and
the raw `FileNotFoundError` aborted application startup.

`GitRepo` now turns an un-runnable `git` (missing working directory, or `git`
not on `PATH`) into a `GitError`, which rollback and restart recovery already
handle — the orphaned job is marked failed and startup proceeds.

## Upgrading

```sh
helm upgrade --install gt oci://ghcr.io/psenna/charts/groundtruth --version 0.0.5 \
  --reuse-values
```

No values you must change — `reasoning_effort` is opt-in. Add it under
`config.defaults.models.default` when you run a reasoning model.
