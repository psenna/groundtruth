# groundtruth v0.0.8

Per-role sampling parameters on a model config.

## `models.<role>.params`

groundtruth's stages — survey, reduce, tag, organize — are extraction and
tool-calling. They want the most-likely output, not sampled variety. But the
client only ever sent `model` / `messages` / `tools` / `reasoning_effort`, so the
sampling settings were entirely whatever the backend defaulted to. For a Qwen3
model that default is `temperature 1`, `presence_penalty 1.5` — tuned for
creative writing, and a direct cause of prose leaking into tag lists, invented
folders, and reworded facts.

`models.<role>.params` is a free-form map merged verbatim into every
chat-completions request for that role:

```yaml
config:
  defaults:
    models:
      default:
        base_url: http://ollama:11434/v1
        model: qwen3:30b-a3b
        api_key_env: GT_API_KEY
        reasoning_effort: none
        params:
          temperature: 0.2       # ingest is extraction; keep it low
          presence_penalty: 0    # a high one drops precise repeated terms
      answer:
        model: qwen3:30b-a3b
        params: {temperature: 0.4}   # a little more latitude for synthesis
```

- Any OpenAI-compatible sampling key works (`temperature`, `top_p`,
  `presence_penalty`, `frequency_penalty`, `seed`, `max_tokens`, `stop`, …);
  Ollama also accepts `top_k`, `min_p`, `repeat_penalty` on its `/v1` endpoint.
- `model`, `messages`, `tools`, and `stream` cannot be set here — the client owns
  them.
- Like `reasoning_effort`, a role inherits `params` from `models.default`; unlike
  it, `params` is **deep-merged** — a role adds to or overrides individual keys,
  it does not replace the whole map.

Empty by default, so existing deployments are unchanged. For a local model the
recommended starting point is `temperature: 0.2`, `presence_penalty: 0` on
`default`.

## Upgrading

```sh
helm upgrade --install gt oci://ghcr.io/psenna/charts/groundtruth --version 0.0.8 \
  --reuse-values
```

No values you must change; add `params` under `config.defaults.models.default`
when you want to pin sampling.
